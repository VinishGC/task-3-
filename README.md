# TechWorld — Electronics & Gadgets

Professional frontend e-commerce internship project.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage for cart, wishlist and demo order state

## Features
Product search, category/brand/rating filters, sorting, product detail specifications, wishlist, cart quantity management, automatic totals, checkout, simulated authentication, responsive design and deal countdown.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Deployment
Can be deployed directly to GitHub Pages, Netlify or Vercel.
